# Security

Smart Build runs commands and stops process groups, so a flaw could run something it should not, signal a process it
does not own, or leave a build running. Please report anything like that privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue for a vulnerability. Include the
version (`smart-build --version`), your OS, and the smallest steps that reproduce it.

Supported: the latest release.
